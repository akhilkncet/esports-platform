## 🎮 JSON Sample for Recording Match Results

```json
{
  "match": 1,
  "team": 1,
  "kills": 18,
  "placement": 1,
  "damage": 15420,
  "survival_time": 1800
}
```

Use this structure to record each team's performance in a match via the MatchTeam model.
